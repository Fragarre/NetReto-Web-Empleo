# Estado consolidado de NetReto Empleo

**Fecha:** 7 de septiembre de 2026

## Arquitectura

- Backend: `Fragarre/NetReto-Web-Empleo`.
- Frontend: `Fragarre/OpoCoach-Web`.
- Base de datos independiente: Supabase `netreto-empleo`.
- Backend desplegado en Render como `netreto-empleo-api`.
- Frontend desplegado en Vercel dentro de NetExamenes.

## Alcance actual

La primera fase de integración se limita deliberadamente a:

1. Generalitat Valenciana (GVA).
2. Diputación Provincial de Valencia (BOP Valencia).

No se continúa todavía con otros organismos.

## Catálogo

Una oportunidad representa un proceso selectivo al que puede interesar acceder al opositor. Las publicaciones posteriores de ese proceso no crean oportunidades independientes.

Las convocatorias cuyo plazo de inscripción ya ha terminado **se mantienen en el catálogo mientras el proceso selectivo siga activo**. `fecha_cierre` es la fecha de cierre de inscripción, no la fecha de finalización del proceso.

Se excluyen, entre otros, procedimientos de promoción interna, libre designación, concurso general de méritos, concurso de traslados, comisiones de servicio, difícil cobertura y acto único telemático.

Estado comprobado: **7 oportunidades GVA + 3 oportunidades Diputación de Valencia = 10 oportunidades visibles**.

## Convocatorias BOP Valencia comprobadas

- 31/24 — 1 plaza de ingeniero/a industrial.
- 150/22 — 4 plazas de profesor/a técnico/a (ingeniero/a técnico/a agrícola).
- 149/22E — 1 plaza de técnico/a auxiliar de obras públicas.

Cada proceso conserva su identidad y la publicación de convocatoria/base se trata como publicación canónica. Las publicaciones posteriores se almacenan como novedades y no sustituyen los datos canónicos del proceso.

## Seguimiento

El usuario autenticado puede seguir y dejar de seguir convocatorias. `Mi seguimiento` muestra:

- convocatorias seguidas;
- novedades de esas convocatorias;
- publicaciones oficiales relevantes;
- cambios relevantes;
- enlace a la fuente oficial.

Las novedades de tribunal se clasifican como `TRIBUNAL`. Se excluyen publicaciones técnicas irrelevantes como las de navegación.

La pantalla utiliza el concepto **«Novedades de mis convocatorias»**. No existe un segundo listado independiente de «últimas novedades».

El aviso de novedades del módulo Empleo conduce a `Mi seguimiento` cuando existen novedades pendientes.

## Notificaciones

No hay envío de correo ni vigilancia programada/cron. El sistema actual detecta y presenta novedades cuando las fuentes son actualizadas y el usuario consulta la aplicación.

## Estado de seguridad pendiente

La tabla `seguimiento_estado_usuario` tiene pendiente la revisión de RLS señalada por Supabase. No se aplica ninguna modificación automática de RLS sin decisión expresa.

## Criterio de continuidad

Este documento sustituye como punto de referencia operativo a las descripciones históricas que indiquen que Empleo sigue en fase inicial o que el catálogo todavía no está integrado en producción. Los cambios futuros deben preservar las reglas anteriores salvo decisión explícita.
